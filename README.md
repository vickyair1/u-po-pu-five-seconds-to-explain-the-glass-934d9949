One sentence, at most 200 characters, in a house cat's own voice — what the
cat would say in the five seconds after sweeping a glass off the table. No
apology, no confession, just the most convincing case the cat can make for
itself.

Entry for [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949)
on [make.fun](https://make.fun).

## The line

> That glass spent all morning blocking my sunbeam, so I moved it to the floor, where it belongs, and I'd do it again.

116 characters. The cat's logic is pure self-interest (the sunbeam is sacred,
the glass was in the way), the idea is fresh — not gravity, not a slippery
edge, not already falling — and the closer doubles down instead of
apologising: it would do it again.

## Run

```sh
python3 main.py
```

Prints the single line to stdout and writes it to `/output/entry.txt`
(override with `MAKEFUN_OUTPUT_DIR`). The program refuses to write a line
that is empty, multi-line, or over 200 characters.
